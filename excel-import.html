Guide: Excel import

Import your records from Excel or CSV

Moving from a spreadsheet or another money app? Export your old records to a sheet, pick the file in Money SpendOptic, check the preview and add them. Nothing is added until you say so.

Make the file

Use one row for each transaction, with a heading in row 1. The app reads .xlsx, .csv, .tsv and .txt files.

  • Needed: Date, Amount, Type (Income, Expense or Transfer) and Account.
  • Helpful: Category, Subcategory, Note, Description, To account (for transfers), Group, and Account no and To account no (the last 4 digits of an account's number).

The import page has a sample file and a layout guide you can open from the phone.

Preview before anything is added

After you pick the file, the app shows how many rows are ready, how many need a look and how many are already in the app. Rows are listed under their day. Going back adds nothing. You can edit or skip any row, and your file is never changed.

Dates, accounts and categories

The app tries day-first and month-first dates and picks the one that reads the most rows. If it cannot tell, it asks you, and shows your file's example date read each way.

A name the app does not know, an account or a category, gets a card: use one you already have, or create it. Account numbers (last 4 digits) tell accounts with the same name apart.

Safe to repeat and easy to undo

A row already in the app (same day, minute, type, account, amount and note) is marked Already added and skipped, so importing the same file twice is fine. Before it adds anything the app saves a backup, and the Last import card on the import page has Undo.

Export back out

From More, Backup and restore you can export to Excel or to a PDF statement. Excel export is free. PDF is a Premium tool, free in your first 30 days. You can pick a month, a year, last year, your own dates or one account. A file exported from the app imports back to the right accounts.

Questions

Can I import from another money app?

If that app can export your records to a sheet, add the needed columns (Date, Amount, Type, Account) and import it. The file layout, not the app, is what matters.

Is my file uploaded anywhere?

No. The file is read on your phone. Money SpendOptic runs no server that collects your data.

What if the import was a mistake?

Tap Undo on the Last import card, or go back to the Before import backup in the backup history.

Can I import the same file twice?

Yes. Rows already in the app are skipped.

Does it work with Google Drive files?

Download the file to your phone first, then pick it from Downloads.
